# LaraKit

A Laravel package providing reusable SEO utilities including meta tags, Open Graph, Twitter Cards, and JSON-LD structured data.

> **Current release:** `v1.0.0`

## Features

LaraKit currently provides:

- Basic SEO meta tags
- Page title
- Meta description
- Meta keywords
- Robots meta tag
- Canonical URLs
- Open Graph metadata
- Twitter Cards metadata
- JSON-LD structured data
- Schema.org schema objects
- Article schema
- Product schema
- Organization schema
- WebSite schema
- BreadcrumbList schema
- Schema `@id` generation
- Schema references
- Schema relationships
- Automatic schema relationship resolution
- Laravel service-container integration
- Configuration support

Additional LaraKit modules, including authentication, image optimization, and admin utilities, are planned for future releases.

---

## Requirements

- PHP 8.3+
- Laravel 13.x
